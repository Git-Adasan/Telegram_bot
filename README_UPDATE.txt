КАК ПРИМЕНИТЬ
1. УДАЛИТЕ старую папку statistics/ (её имя совпадает со стандартным модулем Python и ломает библиотеки).
2. Скопируйте в проект: main.py (заменить), папку stats_render/ (новая), assets/ и covers/ (если их нет).
3. По желанию положите assets/adasan_avatar.jpg — иначе берётся adasan.jpg из корня проекта.
4. В .gitignore добавьте строки:  covers/cache/   и   *.bak
5. Перезапустите бота. requirements.txt не менялся.

ЧТО ИСПРАВЛЕНО
- stats_render вместо statistics (импорт больше не ломает стандартную библиотеку).
- /update_books: не блокирует бота, не записывает пустую базу (при 0 книг или падении >50% база не меняется),
  запись атомарная + копия books_db.json.bak, без лимита 5000 постов, один запуск за раз.
- Избранное и история открываются по message_id (bm_...), а не по индексу: после обновления каталога
  открывается нужная книга. Удалён дубль favorites_button, добавлен запасной вариант удаления для текстовой карточки.
- Избранное ограничено 30 книгами (как на картинке).
- Обложки для /popular: общая блокировка Telethon с /update_books, таймаут 45 с, посты без фото не запрашиваются повторно.
- Определение языка по началу слова («eng» больше не ловит «length», «каз» — «указ»).
- Удалён недостижимый автобан за спам (антифлуд пропускает не больше 2 сообщений за 10 с); словари антифлуда очищаются.
- Карточка многотомной книги: одна кнопка ⭐ и один блок 👍/👎 на всю серию (хранятся на первом томе).
- /popular: на карточке книги показано число лайков (♥) — для серии берутся лайки карточки серии.
- Картинки: подпись внутри панели, названия в 2 строки, высота зависит от числа книг, быстрый градиент, аватар.

НЕ ТРОГАЛ (решение за вами)
- Автобан за мат с первого слова — без предупреждения.
- Старые сообщения с кнопками bk_/rate_/fav_add_ в чатах всё ещё привязаны к индексу; после обновления каталога
  такая кнопка может открыть другую книгу. Новые сообщения создаются корректно.
- В архиве, который вы присылали, были .env с BOT_TOKEN и update_session.session. Отзовите токен в @BotFather
  (/revoke) и завершите сессию в Telegram (Настройки → Устройства), если архив уходил кому-то ещё.

НОВОЕ: ТОП-5 КНИГ ПО ПРЕДМЕТАМ С ВИДЕО (только владелец управляет)
/top5_set гистология <ссылка1> ... <ссылка5>   — задать список (ссылки на посты книг в канале)
/top5_video гистология 1 https://youtu.be/...  — видео к книге №1 ("-" вместо ссылки удаляет)
/top5_del гистология [номер]                   — убрать книгу или весь список
/top5_export                                   — бот присылает top5.json
Пользователи: /top5, кнопка «🏆 Топ-5» в каталоге и в меню предмета (появляется, когда список есть).
ВАЖНО: список хранится в top5.json. На Render диск временный, поэтому после изменений сделайте /top5_export,
положите файл в корень проекта и git commit + push, иначе после деплоя список пропадёт.

НОВОЕ: РЕЗЕРВНЫЕ КОПИИ В TELEGRAM (вместо платной базы данных)
- Бот сам присылает вам в личку zip: adasan_backup_ДАТА.zip и ЗАКРЕПЛЯЕТ его. Внутри:
  adasan.db (вся база), readable/*.csv (пользователи, избранное клиентов, открытия книг, оценки, история — открываются в Excel),
  readable/summary.txt (цифры и топ-10), top5.json, books_db.json.
- Когда: каждые 3 часа (если данные изменились; переменная BACKUP_INTERVAL_HOURS), а также прямо перед остановкой бота при деплое.
- После деплоя, если база пустая, бот сам берёт закреплённую копию и восстанавливается, и пишет вам об этом.
- /backup — копия прямо сейчас (сделайте её один раз после обновления).
- /restore — вручную: перешлите zip боту с подписью /restore или ответьте на zip командой /restore (только владелец).
- Не откреплять и не удалять закреплённое сообщение с копией в чате с ботом.
- Пустую базу бот не копирует и не затирает ею старую копию. Если автовосстановление не удалось, автокопии останавливаются.
- В .gitignore добавьте: *.before_restore
